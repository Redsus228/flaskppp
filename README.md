# 🖼️ Flask Image Collage & RGB Histogram Tool

Веб-приложение на Flask объединяет два изображения по вертикали или горизонтали, автоматически рассчитывает и выводит графики поканальных цветовых RGB-гистограмм для исходных файлов и результата. Доступ к рабочему пространству защищен через Google reCAPTCHA v2.

---

## 🚀 Системные требования

* **Docker Desktop** с запущенным движком Docker Engine.
* Подключение к **Интернету** для валидации капчи на серверах Google.
* Любой современный веб-браузер.

---

## 📦 Быстрый запуск через Docker

1. **Распакуйте архив** с проектом в целевую рабочую директорию.
2. Откройте терминал операционной системы и перейдите в корневую папку приложения
   ```bash
   cd /путь_к_папке/flaskppp
   ```
3. Запустите автоматическую сборку и старт изолированного контейнера в фоновом режиме
   ```bash
   docker-compose up -d --build
   ```
4. Откройте браузер и перейдите по адресу 
   👉 **[http://localhost:8080](http://localhost:8080)**

---

## 🛠️ Инструкция по работе

1. Пройдите проверку **«Я не робот»** на главной странице и нажмите кнопку подтверждения.
2. В открывшейся панели `/collage` загрузите два графических файла в формате `.jpg`, `.jpeg` или `.png`.
3. Установите переключатель направления в положение горизонтальной или вертикальной склейки.
4. Нажмите кнопку запуска обработки, после чего на экране отобразится готовый коллаж и три RGB-графика распределения яркости пикселей.

---

## 🛑 Управление контейнерами

* Проверить активность контейнера
  ```bash
  docker ps
  ```
* Просмотреть журналы логов бэкенда Flask
  ```bash
  docker logs flask_app
  ```
* Полностью остановить проект и освободить порты
  ```bash
  docker-compose down
  ```

## 🛠️ Стек технологий

* **Бэкенд** — Python 3.9, Flask, Gunicorn.
* **Фронтенд** — Шаблоны Jinja2, Flask-Bootstrap.
* **Валидация и безопасность** — Flask-WTF, WTForms, Google reCAPTCHA API.
* **Графика и анализ данных** — Pillow, Matplotlib в фоновом режиме Agg.
* **Автоматизация и DevOps** — Docker, Docker Compose, AppVeyor CI.
